# 🚍 Transport Management System

A web-based Transport Management System developed using **Python Flask, MySQL, HTML, CSS, and JavaScript**.

## 📌 Project Overview

The Transport Management System is designed to simplify and manage transportation activities. It helps maintain driver details, vehicle information, routes, trips, passengers, and bookings in one system.

## ✨ Features

- Driver Management
- Vehicle Management
- Route Management
- Trip Management
- Passenger Management
- Booking Management
- MySQL Database Integration
- Flask REST API

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** MySQL
- **Tools:** VS Code, Git, GitHub

## ⚙️ Installation and Setup

1. Clone the repository.

```bash
git clone https://github.com/prajeethm27/-Transport-Management-System.git
```

2. Open the project folder.

3. Install dependencies.

```bash
pip install -r requirements.txt
```

4. Create the MySQL database using `schema.sql`.

5. Configure your database credentials in the `.env` file using `.env.example` as a guide.

6. Run the Flask application.

```bash
python app.py
```

7. Open your browser and visit:

```text
http://127.0.0.1:5000
```
